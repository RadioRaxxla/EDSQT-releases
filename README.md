# EDSQT — the Squadron Tool for Elite Dangerous

By Radio Raxxla. This page holds the EDSQT downloads, their release notes and the
issue tracker. EDSQT is closed source; its code is not published here.

## Get it

Download `EDSQT-Setup.exe` from the newest entry on the
[Releases](https://github.com/RadioRaxxla/EDSQT-releases/releases) page. It installs for you only (no admin prompt).
Windows 10 or 11, 64-bit. Each release lists the installer's SHA-256.

The build is not code-signed yet, so Windows SmartScreen warns on the first
run: **More info → Run anyway**. Once installed, EDSQT updates itself.

## Report a problem

Open an issue with the **Bug report** form, and quote the version from the
status bar along the bottom of the window. Ideas go in **Feature request**.
Security problems go through the **Security** tab, never an issue.
